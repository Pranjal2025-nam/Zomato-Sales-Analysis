# Zomato-Sales-Analysis
Power BI Dashboard

The cleaned CSV is imported into Power BI, where the following were built:

KPI cards: Total Sales, Total Orders, Average Order Value, Average Rating
Trend charts: Monthly and daily sales trends
Breakdowns: Sales by city, cuisine, restaurant, and payment mode
Slicers/filters: Date, city, cuisine
DAX measures: e.g. Total Sales = SUM(Zomato[order_amount]), Avg Order Value = DIVIDE([Total Sales], [Total Orders])
